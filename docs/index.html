不拿大纲冒充课文。页码、引用、答题都回到可搜索的教材 PDF。

01

教材精读

左侧目录、中间 PDF、右侧本页问答可各自隐藏或拖动。引用写成「选必2第48页」或「必修第一册 P138」即可跳到对应页，预览若已收起会自动打开，回答留在原处。

02

全高中知识图谱

不是单册孤岛。五册考点连成一张图，从节点可以直接跳教材或发起出题。

03

3D 分子实验室

本地 XYZ 结构，原子旁标中文名。拖转、滚轮缩放，一键复位默认视角。也可以按当前分子检索教材提问。

04

流式问答与高考口径

粘贴截图、上传附件，回答按 token 流出并渲染化学式。出题走双模型交叉，再由仲裁模型判定是否入库；支持等级考拼卷与整卷机评。
